HOCKEY LIVE — версия для iPhone (PWA)

Важно: iOS не устанавливает сторонний ZIP как приложение, а открытие index.html из «Файлов» не даст полноценный режим приложения. Для установки без App Store эти файлы нужно опубликовать по HTTPS.

ПУБЛИКАЦИЯ БЕЗ СВОЕГО СЕРВЕРА ЧЕРЕЗ GITHUB PAGES:
1. На github.com войдите в аккаунт, создайте новый Public репозиторий, например hockey-live.
2. Загрузите в корень репозитория все файлы из папки HOCKEY_LIVE_iPhone (НЕ сам zip).
3. В Settings > Pages > Build and deployment выберите Deploy from a branch, branch main, folder /(root), Save.
4. После публикации откройте адрес https://ВАШ-ЛОГИН.github.io/hockey-live/ в Safari на iPhone.
5. Нажмите «Поделиться» > «На экран Домой» > «Добавить».
6. Запускайте Hockey Live с иконки. Для получения расписания нужен интернет.

ФУНКЦИИ:
- НХЛ: расписание и счёт через публичный NHL Web API с CORS-прокси.
- КХЛ: попытка загрузить данные через сторонний спортивный источник, при отказе — официальный календарь.
- Переключение КХЛ/НХЛ, выбор дня, избранное (хранится локально), обновление каждые 90 секунд.
- Трансляции запускаются на официальных сайтах, не внутри приложения.

ОГРАНИЧЕНИЯ:
- Это не нативное приложение App Store и не IPA.
- Работу внешних источников данных в момент сборки нельзя было проверить; возможны ошибки CORS, лимиты и блокировки.
- CORS-прокси — сторонний сервис, не отправляйте через него пароли и персональные данные.
- Не распространяйте нелицензированные видеопотоки.
