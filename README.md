# HOCKEY LIVE v2 · iPhone + Windows

КХЛ / НХЛ / КЛХЛ (Костанайская любительская хоккейная лига).

## Установка на GitHub Pages

1. Откройте репозиторий `snitkonikita1706/HOCKEY-LIVE`.
2. Загрузите **содержимое** этой папки с сохранением путей через Git (рекомендуется GitHub Desktop) или веб-интерфейс. Нельзя помещать всё в дополнительную папку.
3. Файл `.github/workflows/update-khl.yml` должен остаться во вложенных каталогах. Для него удобнее GitHub Desktop, поскольку веб-загрузка часто не сохраняет структуру папок.
4. Pages: `main` + `/ (root)`.
5. В разделе Actions запустите «Обновить календарь КХЛ» через `Run workflow`. Проверьте разрешение Actions на запись: Settings → Actions → General → Workflow permissions → Read and write permissions.
6. Откройте https://snitkonikita1706.github.io/HOCKEY-LIVE/ и добавьте на экран «Домой» через Safari.

## Ограничения

* КЛХЛ: начальная выборка **из 17 подтвержденных матчей**, с датами, счётом и дивизионами по состоянию на 12.11.2026, не автоматический LIVE. Все матчи и переносы проверяйте на официальном сайте `fhkostanay.kz`.
* КХЛ: загрузка GitHub Actions из внешнего источника. Если сервис блокирует запросы, файл `data/khl.json` останется без изменений, а приложение предложит официальный календарь.
* НХЛ: открытый NHL API через внешний прокси, при недоступности прокси результаты не загрузятся.
* Видео не ретранслируется. Кнопки открывают страницы официальных правообладателей или календарь.
* Все даты КЛХЛ записаны в часовом поясе Казахстана UTC+5.
